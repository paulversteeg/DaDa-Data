# Feature design decisions

## DD-UN-001: Shirtontwerp volgt het poster-artwork
- **Date:** 2026-10-20
- **Context:** Het shirt moet visueel aansluiten op de rest van de show.
- **Decision:** Ontwerp afgerond. Gradient wit → enkele bolletjes → zwart, overgenomen uit de poster. De gradient is subtieler gemaakt dan de eerste versie (die was voller).
- **Alternatives considered:** De vollere gradient uit de eerste versie.
- **Status:** Definitief. Het ontwerp is op 2026-10-20 aan iedereen getoond en als definitief besloten. Het moet worden gemaakt en bedrukt; Hans pakt dit verder op.
- **Consequences:** Leverancier moet een doorlopende print met fijne gradient kunnen drukken. Sleeve blijft open en kan later worden toegevoegd.
